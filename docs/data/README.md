# Web-reader data provenance

- `quran.json` is generated from the repository's bundled `quran.db.gz` by
  `scripts/export_web_data.py`.
- `nastaleeq.json` is generated by `scripts/import_nastaleeq.py` from Quran.com's
  public v4 `qpc_nastaleeq` Quran-script endpoint. QUL documents this as the
  matching Unicode script for the KFGQPC Nastaleeq font.

Nastaleeq source endpoint pattern:

`https://api.quran.com/api/v4/verses/by_page/{page}?fields=text_qpc_nastaleeq_hafs`

The `text_qpc_nastaleeq_hafs` field is required for this font. The similarly
named generic `text_qpc_nastaleeq` field uses a different private-use glyph map
and must not be substituted.

The imported file must contain exactly 6,236 unique verse keys, beginning with
`1:1` and ending with `114:6`. It is presentation data and does not modify the
repository's source database.
