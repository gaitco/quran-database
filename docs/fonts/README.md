# KFGQPC Nastaleeq font

`KFGQPCNastaleeq-Regular.ttf` is an unmodified local copy downloaded from the
[Quranic Universal Library font resource](https://qul.tarteel.ai/resources/font/462).
QUL attributes the original Quran font to the King Fahd Glorious Quran Printing
Complex and documents its use with the matching QPC Nastaleeq Quran script.

- Download URL: `https://static-cdn.tarteel.ai/qul/fonts/nastaleeq/KFGQPCNastaleeq-Regular.ttf`
- Downloaded: 2026-08-10
- SHA-256: `de174e33ae14cb581097940de298c8bb9cfa60f7a34d7d0ab0ba2bd5126f912c`
- Size: 254,720 bytes

The font must be used with matching Nastaleeq-script text. It must not be used
to transform or rewrite the repository's source Quran database.

## QPC Hafs font

`UthmanicHafs_V22.ttf` is a local copy of the QPC Hafs Unicode font documented
by the [Quranic Universal Library](https://qul.tarteel.ai/resources/font/245).
It is used for the reader's Uthmani text so Quranic combining marks are shaped
consistently instead of depending on an unknown system fallback font.
